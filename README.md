# AI 相声直播 · 鲸云社（开源版）

几个 AI 角色在抖音直播间里说相声：大模型实时写台词、本地 Breeze TTS 配音、网页画面对口型，观众发弹幕点题、送礼物现挂。

本仓库是程序部分：**导演程序、直播画面、导演台（控制台）、抖音弹幕插件、一键开播脚本、Mac 版 Breeze TTS 部署包**。
角色立绘、背景、声音样本、短视频和直播记录都不在这里，需要换成你自己的。

## 它是怎么运转的

```
抖音直播间 ──弹幕/礼物──► douyinLive（本地 ws:1088）─┐
            └─────────► 浏览器插件（读评论区）────────┤  去重、防假礼物
                                                        ▼
                                原型/server.mjs（导演程序，端口 7860）
     段子库 / 主题库 / 梗库 ─► 导演：排提纲 → 分镜头写台词（多个 LLM）→ 审核弹幕
                                        │            （中转站优先，失败/过慢走官方）
                                        ▼
                         Breeze TTS（本地）配音 → 口型数据
                                        │
                   直播画面（overlay，1920×1080 网页）◄─ SSE ─┘
                   立绘 + 口型/表情贴片 + 动作 + 字幕 + 礼物榜 + 换场黑场
                                        │
                         虚拟声卡 + 直播伴侣窗口采集 → 抖音
```

## 目录

| 路径 | 内容 |
|---|---|
| `原型/` | 直播程序本体：`server.mjs`、`lib/`（导演、配音、弹幕接入、防护）、`public/`（直播画面 + 控制台）、`prompts/`（角色人设）、`config.json`、段子 / 主题 / 梗库、`tools/check-*.mjs` 离线测试、`抖音弹幕插件/`（Chrome 扩展） |
| `工具/` | Windows 一键开播 / 下播脚本 |
| `素材/tools/` | 抠绿幕、切口型贴片、动作分类脚本；素材规范见 `素材/素材清单.md` |
| `tts-mac/` | Apple Silicon Mac 上的 Breeze TTS 部署包（编译脚本、中文网页、桌面控制台、变声唱歌脚本） |

## 快速开始

**需要：** Node.js 22+、Python 3.12（素材脚本，需 Pillow / numpy）、ffmpeg、Chrome、抖音直播伴侣、Breeze TTS 本地服务。Windows 上用一键开播脚本；Mac 上可以用 `tts-mac/` 部署 TTS。

1. **填你自己的 key**：把 `原型/.env.local.example` 复制为 `原型/.env.local`，填上各家大模型的 API key。`.env.local` 已被 `.gitignore` 排除，不要提交。
2. **填你的接口地址**：`原型/config.json` 里 `providers` 的 `baseUrl` 和 `model` 改成你用的服务（官方接口或 OpenAI 兼容的中转站，示例里的 `your-relay.example.com` 是占位符）。
3. **直播间房间号**：第一次运行一键开播时会询问，也可以在控制台里填。
4. **弹幕服务**：下载 [douyinLive](https://github.com/jwwsjlm/douyinLive) v2.3.2 解压到 `工具/douyinLive-v2.3.2/`，按它的 `config.example.yaml` 写好 `config.yaml`，其中 `api.key` 与 `.env.local` 的 `DOUYINLIVE_KEY` 一致。
5. **Breeze TTS**：Windows 版放到 `C:\breeze-tts2`（或用环境变量 `BREEZE_DIR` 指定目录）；Mac 版见 `tts-mac/使用说明.md`。`config.json` 里每个角色的 `voice` 改成你在 Breeze 声音库里保存的声音名。
6. **素材**：按 `素材/素材清单.md` 准备角色立绘、口型贴片和背景。
7. 本地看效果：`cd 原型 && node server.mjs`，浏览器开 `http://127.0.0.1:7860/`（画面）和 `/control`（控制台，可发模拟弹幕和礼物）。

**离线测试**（不连真 API、不占 TTS）：

```bash
cd 原型
for t in tools/check-*.mjs; do node $t >/dev/null 2>&1 && echo "PASS $t" || echo "FAIL $t"; done
```

详细用法见 `原型/使用说明.md`；节目逻辑见 `原型/节目与等待说明.md`；弹幕回复规则见 `原型/弹幕回复设置说明.md`。

## 深深的“跑调清唱”

观众发“唱一个”时，深深会放一段跑调清唱。录音不随仓库分发：想用这个梗，准备一段你自己有权使用的清唱录音（16 位 PCM WAV），放到 `素材/音效/深深-跑调清唱.wav`，并在 `原型/config.json` 的 `director.sing.phrases` 里按乐句起点改时间。没有录音时这个梗自动关闭，其他功能不受影响。

## tts-mac：Mac 版 Breeze TTS

`tts-mac/` 是在 Apple Silicon Mac 上本地编译运行 Breeze-TTS-2.cpp 的部署包，额外加了中文网页和桌面控制台。

- **不含模型和安装包**。部署前需要自行准备：
  - 模型：`breeze-tts-2-f16.gguf` / `breeze-tts-2-q8_0.gguf` 放到 `tts-mac/models/`。
  - 依赖归档：按 `tts-mac/installers/dependencies.json` 里的官方地址下载，放进 `tts-mac/installers/`，部署脚本会校验 SHA256。
- 部署：`tts-mac/一键部署.command`；桌面控制台：`bash tts-mac/panel/install-panel.sh`。
- `tts-mac/tools/sing_convert.py`：用 Breeze 变声把分离好的人声换成别的声音（唱歌效果有限，歌声更推荐 Seed-VC 之类专门的工具）。
