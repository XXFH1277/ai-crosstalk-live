# Windows 版 Breeze TTS

这里是启动脚本、中文网页和模型下载脚本。程序和模型体积大，也有各自的许可，不放在仓库里，要自己下载。

**需要：** Windows 10/11 x64、支持 Vulkan 的显卡（F16 模型约占 6.3 GB 显存，Q8 约 3.6 GB）、Python 3.12。

## 安装

1. 把 `tts-windows` 整个文件夹复制到 `C:\breeze-tts2`；放别的位置也行，把环境变量 `BREEZE_DIR` 设成那个目录。
2. 下载运行程序：打开 [Breeze-TTS-2.cpp v0.1.3](https://github.com/HoppouAI/Breeze-TTS-2.cpp/releases/tag/v0.1.3)，下载 Windows x64 Vulkan 版，解压到 `runtime\` 里，确保里面只有一个 `breeze-server.exe`。
3. 下载模型（支持断点续传，下载完会校验 SHA256）：

   ```bash
   pip install requests
   python download_model.py --model f16
   ```

   想省显存就把 `f16` 换成 `q8`，并把 `config.json` 的 `model` 改成 `breeze-tts-2-q8_0.gguf`。

## 启动

- 双击 `Start-F16.cmd` 或 `Start-Q8.cmd`，就绪后会打开中文网页 <http://127.0.0.1:8080/>。
- 用完双击 `Stop-Breeze.cmd` 释放显存。
- 一键开播脚本会自动启动它，不用手动开。

## 声音

仓库不带声音。在网页的声音设计页面生成并保存声音，再把保存的名字填到 `原型/config.json` 里对应角色的 `voice`。

更多细节见 `README-本地使用.md`（那是作者本机的部署记录，路径和结果仅供参考）。
