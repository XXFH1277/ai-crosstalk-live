# mindcraft 配音台（7862）

深深、月月在 Minecraft 里由 **mindcraft** 驱动：自己找活干、挖矿、合成、互相斗嘴。配音台只负责三件事：

1. 听：订阅 mindcraft 的 MindServer（默认 8091）推出的每一句话；
2. 念：用 Breeze F16 配音（复用 `原型/minecraft/services.mjs` 的配音和受击短音）；
3. 画：网页上的立绘按音量动嘴型，可以弹出置顶双人窗盖在游戏上方。

不替 mindcraft 做决定，也不执行任何游戏动作。

## 启动顺序

1. **确认直播伴侣没在推流**（或者确认要在直播里放游戏）。
2. 启动 Breeze：`<Breeze 安装目录>\start-breeze.ps1 -Model F16 -NoBrowser`
3. Minecraft 1.21.6（PCL 实例 `1.21.6-Fabric-Skins`）打开世界 →“对局域网开放”。
4. 启动 mindcraft：在 `工具/mindcraft` 下运行 `node main.js`（自动找局域网端口；会弹出 8091 管理页，可以关掉）。
   - **不要同时开 7861 游戏台**，两边的 bot 名字一样。
5. 启动配音台：在 `原型` 下运行 `node minecraft-mindcraft/server.mjs`，用 Chrome / Edge 打开 `http://127.0.0.1:7862/`。
6. 点「开启声音」；需要盖在游戏上就点「打开置顶双人窗」。
7. 在「给两人下长期目标」里写目标（mindcraft 每次重启都要重新下）。也可以在游戏里按 T 直接跟她们说话。

## 和 7860 相声台的关系

- 7860 在运行：配音台会请求接管播放权，等相声台说完当前这句、让出来以后才开始播；点「暂停声音」会交还。
- 7860 没开：直接单独播放。
- 直播弹幕暂时没有转给游戏里的两人（接管时不会拿走 7860 的弹幕）。

## 配音跟不上怎么办

mindcraft 说话比配音快。规则：最多 3 句排队等配音；超过 25 秒还没播的句子跳过（页面「最近台词」里标“已跳过”，游戏聊天栏仍然看得到）。

## 对 mindcraft 做过的改动（在 `工具/mindcraft`，第三方目录不进仓库）

- `settings.js`：1.21.6、自动找局域网端口、MindServer 端口 8091（8080 是 Breeze 的）、聊天里不显示 `!命令`、不发英文行为播报、人设文件在 `鲸云社/`。
- `src/utils/mcdata.js`：入服后同步 CPM 立体模型（直接用 `原型/minecraft/cpm.mjs` 和 `models/`）。
- `src/agent/vision/*.js`：视觉模块改成用到才加载（本机没装原生 canvas/gl）。
- `patches/mineflayer+4.33.0.patch`：修了新版 minecraft-data 速度字段改名导致的 NaN 踢人，并加了坐标/视角非法值兜底。

## 小工具

```bash
node 原型/minecraft-mindcraft/mc-ctl.mjs state                   # 两人位置、血量、背包
node 原型/minecraft-mindcraft/mc-ctl.mjs say YueyueBot "过来帮忙"  # 以玩家身份跟 bot 说话
```

离线测试：`node 原型/tools/check-mindcraft-voice.mjs`（台词清洗、排队丢弃、播放确认、受击判断）。
