# 形象素材清单

做法：PNGTuber 式分层立绘（不做 Live2D）。每个角色先出一张**基础立绘**，其余帧都基于它做局部改动，再由脚本把改动区域贴回基础图，保证除了眼睛和嘴以外每个像素都一致，切换时画面不跳。

生成：Codex（桌面版 CLI，`image_generation`）。背景统一用 #00FF00 绿幕，之后用脚本抠成透明 PNG。

## 每个角色

| 文件 | 用途 | 说明 |
| --- | --- | --- |
| `基础.png` | 待机 | 双眼睁开、嘴闭合微笑，竖版 1024×1536 半身 |
| `嘴-半张.png` | 口型 | 只改嘴，说话时按音量在 闭/半张/张大 之间切换 |
| `嘴-张大.png` | 口型 | 只改嘴 |
| `眼-闭.png` | 眨眼 | 只改眼睛，每 3~6 秒随机眨一次 |
| `表情-开心.png` | 谢礼物、包袱落地 | 眼和嘴都改 |
| `表情-惊讶.png` | 大礼物、被拆穿前一秒 | |
| `表情-得意.png` / `表情-无语.png` | 深深抛包袱 / 月月吐槽 | 两人各自的招牌表情 |
| `表情-害羞.png` / `表情-坏笑.png` | 深深傲娇 / 月月损人 | 带脸红或挑眉 |

## 目录约定

- `深深/`、`月月/`：Codex 原始输出（绿幕），不要手改，重做时直接覆盖
- `透明/`：脚本生成的成品，改了原始图后重新运行 `python tools/merge_frames.py 深深`（或 月月）
- `prompts/`：每次发给 Codex 的提示词和它的回复，方便重做或追加帧

## 已知小问题
